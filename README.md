# SpendWise

SpendWise is a personal expense and budget management web application designed to help users track their spending, manage their budget, and understand their financial habits through a simple and clean interface.

## Features

- Responsive landing page
- User signup and login interface
- Client-side authentication using LocalStorage
- Hash-based navigation without page reloads
- Expense tracking
- Budget management
- Spending analytics
- Category-wise spending insights
- Responsive design for different screen sizes
- Persistent browser-based data storage
- Interactive UI elements and hover effects
- Animated financial image reel on the landing page

## Tech Stack

- HTML5
- CSS3
- JavaScript
- LocalStorage
